Lumen Maze — gather every crystal, wake the portal, and escape the maze before the shadows catch your light. A complete browser game in plain static files: no library, no network request, keyboard and mouse. Three lights, two minutes, eight crystals, one way out — and a deeper maze after every escape.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
